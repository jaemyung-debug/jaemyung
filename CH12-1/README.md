# 실습과제 1번
## 16MB 메모리의 주소의 범위를 구하시오.
>16*1024*1024-1 이므로 0~(16*1024*1024-1)이다.

## 변수의 주소를 설명하시오. 
>변수가 차지하고 있는 공간의 시작 번지

## 변수의 주소의 자료형은 무엇인가?
>주소가 가르키는 변수의 자료형

## 포인터란 무엇인가?
>주소를 저장하기 위한 변수

## 포인터의 자료형은 무엇인가?
>포인터에 저장될 주소의 자료형

## 변수의 주소를 int형 변수에 저장하면 어떻게 되는가
>컴파일 오류가 발생한다
